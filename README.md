# Cross-Task Prompting Suite

Reference implementations maintained in this repository for our cross-task
prompting research.

| --- | --- | --- |
| Sequential Prompt Chaining for Structured Reasoning | `sequential_prompting/` | Released (v1.0.0) |

source tree contains scaffolding only; no trained router and no evaluation
scripts have been published for that module yet.
